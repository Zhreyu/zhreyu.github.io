A text-to-comic strip generation project that leverages advanced deep learning techniques to transform textual descriptions into engaging comic strips.

## Key Features

- Python-based Reddit crawler for dataset creation (1000+ images)
- Fine-tuned flux-dev model using Low Rank Adaption (LoRA)
- Automatic data annotation pipeline using Large Vision Model
- Deployed on Hugging Face with 20,000+ downloads

## Technical Details

The project utilizes state-of-the-art techniques in computer vision and natural language processing to generate comic strips from text descriptions. The model was fine-tuned using LoRA to maintain efficiency while achieving high-quality results.
